## 新增全局「卡片鼠标亮光」效果
- 新增 `src/composables/useMouseGlow.ts`：document 级 pointermove 事件委托（仅 `pointerType === 'mouse'`，触屏不触发），为带 `.glow-card` 类的卡片更新 `--glow-x/--glow-y` CSS 变量；单个全局监听器 + passive，不为每张卡片单独绑事件；受 `html.glow-enabled` 类门控。
- `src/styles/main.scss`：新增 `.glow-card::after` 径向渐变柔光（300px circle），颜色 `color-mix(in srgb, var(--primary-color, #18a058) 18%, transparent)`，自动跟随主题主色与明暗模式；hover 淡入 200ms；`prefers-reduced-motion` 下禁用过渡。
- 应用到四类卡片表面：NodeCard（节点卡片）、NodeGeneralCards（5 张数据总览卡）、NodeList 行、LoadChart 图表卡片；InstanceDetail/PingChart 无 NCard，未涉及。
- komari-theme.json 新增「视觉效果」分组 + `cardMouseGlow` 开关（type: switch, default: true）；app store 新增 `cardMouseGlow` computed（默认 true）。
